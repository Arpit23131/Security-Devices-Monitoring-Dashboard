# Security Devices Monitoring Dashboard

## Overview
A Flask-based real-time security monitoring dashboard developed during internship at the National Informatics Centre (NIC). The system integrates REST APIs and backend processing to monitor security devices, visualize analytics, and display live monitoring data through a dynamic dashboard.

## Features
- Real-time security device monitoring
- REST API integration
- Live traffic and session analytics
- Dynamic dashboard visualization
- Backend JSON data processing
- Device status monitoring
- Attack/session visualization

## Tech Stack
- Python
- Flask
- REST APIs
- HTML
- CSS
- JavaScript
- Chart.js
